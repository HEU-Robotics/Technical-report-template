# 交给 AI 的排版任务

请先完整阅读仓库根目录的 AGENTS.md，然后执行以下任务：

1. 读取 draft/ 中的全部草稿和 figures/ 中的现有图片。
2. 先列出“草稿内容 → 报告章节”的对应关系，以及缺失、冲突或需要作者确认的信息。
3. 仅依据草稿整理 report-info.tex 和 sections/。不新增事实、数据、引用、实验结果或结论，不覆盖原始草稿。
4. 按模板规范处理标题层级、段落、图表、公式、标签和交叉引用。
5. 运行 scripts/verify.ps1，修复所有编译、路径和引用问题。
6. 输出一份简短变更摘要，并单独列出仍需作者确认的问题。

作者确认内容后，再运行严格检查并清除所有占位符。
